\chapter{Discussion}\label{chap:discussion}

This thesis introduces a novel prediction system for real-time interactive musical performance, building upon the IMPSY system. The core innovation lies in integrating a Monte Carlo Tree Search (MCTS) algorithm with a Mixture Density Recurrent Neural Network (MDRNN) to guide musical predictions. Unlike previous approaches that rely on random sampling from a Gaussian Mixture Model (GMM), our system employs a heuristic-based search to ensure musical coherence and expressiveness. The research specifically focuses on the call-and-response mode of IMPSY, using a monophonic 2D keyboard as a proof of concept. The evaluation demonstrates that the MCTS-enhanced system significantly improves prediction accuracy and qualitative aspects like playability and expressiveness, especially in structured improvisations, by generating more musically coherent outputs.

\section{Impact}
The integration of MCTS and heuristic-based guidance into the IMPSY system offers significant advancements for New Interfaces for Musical Expression (NIMEs) and human-computer interaction as a whole. Our research serves as a proof of concept for the potential that search integration with current machine learning prediction and interaction systems can have.

The most obvious area of impact for this research is on musical prediction systems. By leveraging MCTS to guide machine learning based predictions, prediction accuracy improved significantly. Of course, this research has had a direct impact on the performance of the IMPSY system~\citep{Martin2019IMPSY}, but it has implications for the field as a whole. Prediction systems which use rule-based approaches or markov models for prediction, such as the Continuator by~\cite{Pachet2002Continuator} or the CONCERT system by~\citep{Mozer1994CONCERT}, can have their prediction ability converted into a component heuristic, and then integrated into a neural network based system such as the set of interactive systems developed by~\cite{Collins2007InteractiveMusic}. This can of course be extended to any neural network based system being combined with any number of rule or markov based systems, each of which can be used to create a heuristic component for the MCTS search. By combining systems with different strengths, the weaknesses of each system can be mitigated, and the strengths of each system could be combined to create a more powerful system. This doesn't require combined pre-existing systems however, as MCTS-IMPSY acts as a broad proof of concept for the idea of combining search with any machine learning based system for music generation, and this has a large impact on future research methodology and direction in these fields, allowing developments in each to more directly impact each other.

This thesis also has significant implications for research into any interactive artistic system which functions with call-and-response generation. Each component heuristic is fine tunable and editable, and so by creating a user interface for the heuristic components of the system, the user can have significant control over the system's output. This allows for previously entirely generative composition systems to be modified to allow for a human to influence the system's output over time, and for interactive systems to allow for a human to influence the system's output over time, shifting compositions in a direction shaped by the human user, even when that user is not actively performing. This has significant implications for the future of interactive systems as a whole. For example, a non-interactive music generation approach, such as DeepBach~\citep{Hadjeres2017DeepBach} which attempted to generate convincing chorale harmonizations in the style of Bach, could by shifting to an MCTS prediction process add heuristic components such as tempo, key signature, and other musical parameters. Instead of using these to improve prediction accuracy, they could by default be disabled, meaning that DeepBach would function as normal, but could be enabled and modified by a user as DeepBach was composing, allowing a human user to guide the composition process toward particular stylistic choices. Applying this concept generally, any generative music system could be modified into an interactive system using this approach, which has a large impact on the field, as typically these two types of systems have been researched separately.

Interactive systems are also impacted by the generalisability and customisability of the system. The ability to create and modify heuristics provides a flexible framework with can be adapted to many fields. This include non-musical fields, such as generative visual art, text, and video, where the same concept of using heuristics to guide generative processes could be applied. Within the musical setting, gestural performance systems could train machine learning models on individual and hard to formally define control parameters such as mood, and then link them to a body part or action, so that a system could be created which creates generative music, but with individual control parameters trained on human input being controlled by human gestures. Another subfield where this concept could have significant impact is the hyperinstruments project by~\cite{Machover1989Hyperinstruments}, which has influenced the creation of a multitude of instruments over recent decades which include enhanced control capabilities for humanh performers through the development of complex mapping systems. Integrating the research from this thesis, hyperinstruments could implement partially generative components to instruments, where certain aspects are controlled by the human performer. For example, hyperinstruments could be created where the controls of a human performer influence heuristic components which provide strong guidance for a prediction system which outputs each note. 

This research also bridges the gap between musical research and research into other field where combined MCTS and machine learning systems are used. This includes game playing, natural language processing, and robot motion planning. The use of similar techniques to these fields provides a framework for potential crossover between these fields. For example, a modified version of our system could be used within the game AI field to create musical games where the search tree is generated using our systems approach. Crossovers with robot motion planning could also be made, for example robot instrument playing. These crossover applications do not have to be a mix of the two fields however, as there is likely even more impact provided by the new link in system architecture between these fields. For example, robot motion planning research using C-MCTS search has assisted in the development of many new advanced search techniques, such as the KR-AUCB C-MCTS selection strategy~\citep{Lei2021KBTree}, and now whenever these new developments in the robot motion planning field are made, they can be applied to the musical domain as well. This is a significant impact of this research, as it allows for the two fields to share and develop new techniques together, rather than having to develop them separately.

Impact can also be found in human performance parameter detection. Our system is able to detect and track human performance parameters, and then use these to inform the MCTS search. Hence, this links our research to all other research where musical parameters such as genre, mood, etc are tracked. There is now a way to link these detection based papers into interactive systems, by utilising their parameter detection systems to generate heuristics which can inform interactivity and prediction. For example research into mood detection in music, such as in~\cite{Lu2006MoodDetection} could be directly applied to generative musical processes aiming to be able to control the mood of generated musical output by integrating its findings into a heuristic component in an MCTS based prediction system. Our method of using performance parameter detection to inform heuristics which guide musical output could also be very using for collaborative networked performance. ~\cite{Weinberg2018MultiHumanRobot} developed a system where AI and human performers must interact and improvise in real-time, and if these AI were continuously tracking musical parameters in the human performance, they could use a combined search and neural network generation process to generate musical outputs which more coherently match with the human improvisation.

\section{Limitations}
While the results of this thesis are strong and offer promising potential, there are several limitations to the current system and how it was evaluated. These limitations are important to note, as they provide context for the results, balance the potential impact and scope of this research with what has actually been achieved, and provide a basis for future work.

Firstly, human performance parameters, such as key signature and tempo, were assessed and used statically in the system. For example, the improvisational dataset contained many sections where tempo would slowly increase or decrease, and generally flow as the performance progressed. However, tempo calculations were made on the assumption that if there was a clear tempo, it would be static for the entire duration of the output memory, and this also applies to parameters calculated for other component heuristics, such as key and mode. Ideally, detection of parameters should be done constantly, tracking changes over time, and hence gaining a more accurate understanding of the current state of the performance. This could be done by both recording parameters at each time step, and by modifying heuristic components that rely on static parameters. For example, while the work of~\cite{Laroche2001TempoEstimation} which relies on static tempo was used as the basis for our tempo parameter, other methods, such as the one by~\cite{Scheirer1998TempoTracking}, are designed to be able to track changing tempos, and this research could be used as the basis for the heuristic component instead. Another limitation is that detected performance parameters are left constant throughout the duration of the systems output, and are only modified once the human performer takes over again and changes them. Given that in human performances these parameters are often constantly shifting, ideally this would be recognised and accounted for by the system. This limitation could be mitigated by training a second LSTM-RNN to take the change in parameters over time during human performance, and use this to predict the next state of the parameters at each time step during the system's output.

The computational cost of using MCTS with as MDRNN prediction for the generation of each nodes action space is very high. The evaluation showed that with a 12th Gen Intel Core i7-12700H processor, each MCTS iteration would take 1.6ms on average, leading to practical use cases often being able to utilise less than 100 iterations for each prediction. This is also with a simple 2D instrument, and for another instrument where more dimensions are tracked and involved in the heuristic, this could slow down performance even more. Fortunately, figures ~\ref{fig:improv_nodes_to_accuracy} and ~\ref{fig:nottingham_nodes_to_accuracy} displayed how even with tiny numberts of iterations, the system was able to achieve a significant improvement in prediction accuracy. But, the current number of iterations were not close to the estimated maximum potential performance of the system estimated by these figures, and so optimisations would be helpful. One of the main limitations in the system design causing potentially unnecessary computational cost is the use of the full MDRNN to generate simulations during each iteration. MCTS was designed to use random selection during the simulation phase~\cite{Coulom2006MCTS}, and so computationally cheap simulations are the norm. However, because there is no known action space for musical continuations without the use of a neural network, cheap simulations are more complicated to devise in this context. Possible approaches include using a much more simple model for simulation predictions, or even switching to a markov model or rules based approach for the simulation phase.

Another notable limitation of this system is its scope. Since the type of method used in this thesis is entirely novel for an interactive musical system, this thesis was always intended to serve only as a proof of concept for the type of prediction system developed in this thesis. While the strong results of this approach are enough to warrant further research, there is no firm proof that the system is generalisable to other instruments, genres, or even improvisational contexts, despite this generalisation potential being one of the key motivations for this research. Unfortunately, the scope of a research project evaluating whether this approach is truly generalisable is outside of what was possible in this thesis, and so will have to be left for future work.

While results were very strong, it is also important to note that they were considerably stronger for more structured datasets and performances than they were for freeform ones. Prediction accuracy was much higher for the more structured Nottingham dataset than it was for the improvisational dataset, and the qualitative evaluation of the improvisational dataset showed that the while MCTS-IMPSY was better to perform with for both structured and freeform improvisation, the difference was much more pronounced for structured improvisations. This could be because specific heuristic components such as the key signature, tempo, and repetition heuristics are much more relevant in structured improvisations, but it also could be that even despite this the system is not as good at freeform improvisation. This is relatively unsurprising given that rules-based an heuristic based systems generally follow this trend, and this was the component that was added to IMPSY, but it is worth noting regardless.

There were also limitations with the methodology used to evaluate the system. The quantitative evaluation was conducted using two datasets, one of which was a structured dataset and one of which was an improvisational dataset. While this is a good start, it would be beneficial to conduct further evaluations on a wider range of datasets, including more structured and freeform improvisations, as well as different instruments and genres. This would provide a more comprehensive understanding of the system's performance and its generalisability across different musical contexts. The quantitative evaluation was also conducted on note by note prediction accuracy, but did not test prediction ability over longer phrases, or account for how poor incorrect predictions were. The qualitative evaluation was also limited in scope, as I was the only participant, and an evaluation from an audience perspective was not conducted. These types of qualitative evaluations were beyond the scope of this thesis, but would be beneficial for future work. MDRNN-IMPSY was also used as the control for the entire evaluation, however, it culd have been beneficial to add a state-of-the-art rule or heuristic based prediction system as a second control, to verify that the combined approach improves upon both approaches individually.
