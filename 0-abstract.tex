\chapter*{Abstract}

Interactive musical prediction systems are a significant subfield of New Interfaces for Musical Expression (NIME). These systems can perform collaboratively in a call-and-response manner with a user, with a recurrent neural network (RNN) being a common choice for training the system to predict and hence continue on from human improvisations in real-time. In musical predictions, there is never one correct answer for what the next note should be, and so machine learning systems often rely on random sampling from a distribution of possible note options to generate a prediction. However, this random sampling is entirely arbitrary, and does not take into account how well each potential note fits into the context of the musical piece being played. This can lead to a lack of musical coherence in generated predictions, but with the benefit of increased creativity and expressiveness. In contrast, older generative music techniques often used rule-based approaches, which were excellent at producing coherent music which adheres to musical rules, but lacked the expressiveness and creativity of modern machine learning systems. This thesis introduces a novel musical prediction architecture which combines the stengths of both approaches, by using repeated neural netowrk predictions to generate a search tree of possible musical continuations, which is searched using MCTS search and heuristics inspired by rules-based approaches to ensure musical coherence. Our evaluation showed 67.5\% and 145.2\% improvements in prediction accuracy respectively for two different datasets, and qualitative analysis of improvisations performed with the system showed that this increase did not come at the cost of expressiveness, with the playability and practical usefulness of the system being significantly improved with our prediction architecture. This work represents a significant advancement for NIME and human-computer interaction, showcasing the potential of combining search algorithms with machine learning in interactive artistic systems.
